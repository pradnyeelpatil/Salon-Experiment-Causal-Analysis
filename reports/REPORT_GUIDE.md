# Report submission guide

Run `python run_project.py` first. The pipeline generates:

- `Experiment_Design.docx`
- `Decision_Memo.docx`
- `Project_Report.docx`

Submit `Project_Report.docx` to the YuvaIntern Word-report upload field. Keep the experiment
design and one-page memo as supporting deliverables. Add your own name, internship details,
college details, and screenshots only if required by your evaluator.

**Do not remove the synthetic-data disclosure.** If YuvaIntern later supplies the official
dataset, rerun the pipeline and update the report to describe the real data accurately.
